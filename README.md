# btn-theme

A dark custom stylesheet for BroadcasTheNet. It uses a two-row top header in place of the side menu and a cleaner torrent list.

Paste this into the external stylesheet setting on your profile:

```
https://gl0ryus.github.io/btn-theme/btn.css
```

To update it, edit `btn.css`, commit and push. GitHub Pages serves the new version within about a minute.

Credits: built on the original BTN stylesheet by Starblaster100 and PuNkFuSe, and on the BTN Sideways Mod by Prism16.
